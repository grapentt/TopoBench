# Benchmarking Quick Reference

## 🚀 One-Line Commands

```bash
# Quick validation (~5-10 min)
.venv/bin/python benchmarks/run_benchmarks.py --config quick && .venv/bin/python benchmarks/generate_report.py --results results --output results/REPORT.md

# Standard benchmarks (~15-20 min)
.venv/bin/python benchmarks/run_benchmarks.py --config standard && .venv/bin/python benchmarks/generate_report.py --results results --output results/REPORT.md

# Publication quality (~45-60 min)
.venv/bin/python benchmarks/run_benchmarks.py --config publication && .venv/bin/python benchmarks/generate_report.py --results results --output results/REPORT.md
```

## 📊 Common Customizations

```bash
# Scale all data sizes (easiest way to make benchmarks bigger)
.venv/bin/python benchmarks/run_benchmarks.py --config publication --scale 2    # 2× larger
.venv/bin/python benchmarks/run_benchmarks.py --config publication --scale 10   # 10× larger
.venv/bin/python benchmarks/run_benchmarks.py --config standard --scale 5       # 5× larger

# Large memory test
.venv/bin/python benchmarks/run_benchmarks.py --config standard --memory-sizes 1000 5000 10000

# More parallel workers
.venv/bin/python benchmarks/run_benchmarks.py --config standard --parallel-workers 1 2 4 8 12 16

# More runs for better statistics
.venv/bin/python benchmarks/run_benchmarks.py --config standard --parallel-runs 5 --output results

# Custom everything
.venv/bin/python benchmarks/run_benchmarks.py \
    --memory-sizes 500 2000 5000 \
    --parallel-samples 3000 --parallel-workers 1 2 4 8 \
    --storage-samples 1500 \
    --output results_custom
```

## 📁 File Locations

- **Configs**: `benchmarks/configs/{quick,standard,publication}.yaml`
- **Main runner**: `benchmarks/run_benchmarks.py`
- **Report generator**: `benchmarks/generate_report.py`
- **Template**: `benchmarks/templates/BENCHMARK_REPORT_TEMPLATE.md`
- **Results**: `results/` (or custom via `--output`)

## 📋 Output Files

```
results/
├── RESULTS_SUMMARY.txt          # Text summary (auto-generated by run_benchmarks.py)
├── BENCHMARK_REPORT.md          # Markdown report (generated by generate_report.py)
├── memory/
│   ├── raw_data.json
│   ├── memory_comparison.png
│   └── summary.txt
├── parallel/
│   ├── raw_data.json
│   ├── speedup_curves.png
│   └── summary.txt
└── storage/
    ├── raw_data.json
    ├── storage_comparison.png
    └── summary.txt
```

## ✅ Workflow

1. **Run benchmarks**: `python benchmarks/run_benchmarks.py --config {quick|standard|publication}`
2. **Check text summary**: `cat results/RESULTS_SUMMARY.txt`
3. **Generate markdown**: `python benchmarks/generate_report.py --results results --output REPORT.md`
4. **View report**: `cat REPORT.md` or open in editor

## 🎯 Target Values

| Metric | Target | Config for Clear Results |
|--------|--------|-------------------------|
| Memory O(1) | Slope ratio >10× | 5K-10K samples (publication) |
| Parallel Speedup | 4-8× | 2K-5K samples (standard/publication) |
| Mmap I/O | 2-3× | 1K-2K samples (standard/publication) |
| LZ4 Compression | 1.3-1.6× | Any size (quick works) |

## 🔧 Troubleshooting

```bash
# If benchmarks fail
.venv/bin/python benchmarks/memory_profiling.py --sizes 100 500 --output /tmp/test

# If report fails
ls results/*/raw_data.json  # Check files exist
python -m json.tool results/memory/raw_data.json  # Validate JSON

# Check dependencies
pip list | grep -E "torch|numpy|matplotlib|psutil|yaml"
```
